# SUPERMARKT — немецкий в магазине

Лендинг-разбор темы «Im Supermarkt»: слова с артиклями, фразы, живой диалог,
реалии немецких магазинов (Pfand, воскресенье, платный пакет) и блок про платформу
[Stellas](https://app.lava.top/801303618?tabId=products&sort=published).

## Что внутри

- **Цветовой код артиклей** — `der` голубой, `die` розовый, `das` жёлтый, через все 110+ слов
- **Озвучка** — тап по любому немецкому слову произносит его через Web Speech API.
  Голос и скорость выбираются в панели «Голос»; выбор хранится в `localStorage`
- **Анимации по теме** — конвейерная лента, печатающийся чек, Pfandautomat,
  качели-антонимы, пошаговый диалог
- Mobile-first, `prefers-reduced-motion`, без внешних зависимостей кроме Google Fonts

## Разработка

```bash
python3 -m http.server 4173
```

Открыть `http://localhost:4173`. Параметр `?nofx` отключает анимации появления —
удобно для проверки вёрстки.

## Сборка self-contained версии

```bash
python3 build-artifact.py
```

Кладёт в `dist/` один HTML-файл со всеми картинками и видео, вшитыми как `data:` URI.

## Структура

```
index.html            весь сайт: разметка, стили, скрипты
assets/logo.png       логотип
assets/platform/      скриншоты платформы
assets/reviews/       отзывы
assets/video/         демо-видео (сжатые mp4)
build-artifact.py     сборщик автономной версии
```
